# Third-party assets and their licences

> **Rule: nothing ships until its row exists here.**
>
> An asset whose licence is not written down is an asset that has to be removed
> later, usually at the worst possible moment. Add the row when you download the
> file, not when you finish the feature.

Every asset is **downloaded once, vetted, committed to `public/`, and served
same-origin**. The Content Security Policy is `default-src 'self'` (see
`vercel.json`), so there is no CDN and no runtime fetch from anywhere else. This
is a security posture, not a preference.

Acceptable licences: **CC0**, **CC-BY** (attribution recorded below), **SIL OFL**
(fonts), **MIT/Apache-2.0** (code). Anything with a non-commercial or no-derivatives
clause is not acceptable — record why an asset was rejected if it is one someone
is likely to propose again.

## 3D models

| File | Source | Licence | Attribution required | Notes |
|---|---|---|---|---|
| `public/models/craft.glb` | [Kenney Space Kit](https://kenney.nl/assets/space-kit) — `craft_speederA.glb` | CC0 1.0 | No attribution required (CC0) | Compressed with gltf-transform v4.4.2 (meshopt). Player craft. |

The three hostile archetypes are **not** assets and have no row here. They are
built at startup by `src/render/geometry/shapes.ts`, which is original work in
the repository like any other source file.

They were briefly `public/models/{harvester,interceptor,sentinel}.glb`, produced
by a `tools/generate-enemy-models.mjs` that assembled them from the same
Three.js primitives and exported the result — so the pipeline round-tripped code
through an asset and gained nothing, while adding three requests, 42 KB, a
loader on the hot path, and a hand-tuned scale factor that drifted 8–18× away
from the collision radii. Both the files and the generator were removed; see
`tests/unit/models.test.ts` for the invariant that replaced the guess.

Preferred sources, all CC0 unless a specific asset says otherwise:

- **Kenney Space Kit** — <https://kenney.nl/assets/space-kit> — CC0
- **Quaternius Ultimate Space Kit** — <https://quaternius.com/> — CC0
- **Poly Haven models** — <https://polyhaven.com/models> — CC0

Record the exact asset name and URL, not just the site. "A ship from Kenney" is
not a licence record.

## Runtime dependencies

Licences of npm packages are not listed individually — `package.json` pins exact
versions and `npm audit` runs clean. The constraint that matters is architectural
rather than legal: **no dependency may be loaded from a CDN at runtime.**
Everything is bundled by Vite and served from the same origin.
